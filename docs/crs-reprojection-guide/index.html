Advanced GIS

Assign and reproject a coordinate reference system

Keep imported data in the correct real-world position, inspect projected coordinates and export a layer in the CRS required by another GIS.

Privacy

Detection, coordinate transformation and export happen in your browser. EditPolygon does not upload the layer to a processing server.

Open the CRS tools

  1. Import or select an editable layer.
  2. In the Layers panel, open the layer’s GIS menu.
  3. Choose CRS.

Assign versus reproject

Assign metadata only

Use this when the layer is already in the correct map position and you only need to document its original/native CRS.

Interpret current coordinates and reproject

Use this only when projected easting/northing values were imported as though they were longitude/latitude and the layer is misplaced or invisible.

Automatic detection

EditPolygon reads legacy GeoJSON CRS metadata, Shapefile PRJ files, GML srsName values and ArcGIS FeatureServer spatial-reference metadata. When coordinates fall outside longitude/latitude range and no supported CRS is known, the layer is flagged for manual interpretation.

Export in another CRS

  1. Choose the required export CRS.
  2. Select GeoJSON, Shapefile ZIP, WKT or CSV.
  3. Download the layer. Shapefile exports include matching PRJ files.

Accuracy note

Web Mercator and UTM/MGA projection calculations are performed locally. GDA94 and GDA2020 datum conversion uses a general zero-parameter approximation; use an authoritative grid-transformation workflow for survey-grade cadastral work.
