Merge polygons online

Merge is a geometry and data-model decision, not just a visual action.

What merge / dissolve does

Merge combines selected polygon areas and removes boundaries that are genuinely shared or overlapped. It does not invent connections across gaps. Touching or overlapping areas normally produce one Polygon; separated areas normally produce a MultiPolygon.

Merge changes feature structure. Several source features become one result. Save the original project or source file first, and decide how the merged feature should be named and attributed.

1. Select the polygons

  1. Select the main polygon.

    Click it on the map or in Layers.

  2. Add other polygons.

    Use Ctrl-click on Windows/Linux, Command-click on macOS or Shift-click for a range. Checkboxes also select features without changing visibility.

  3. Confirm the selection count.

    The contextual selection bar should report two or more selected polygons.

2. Run Merge / dissolve

Select Merge / dissolve from the contextual selection bar. The same operation is available from Geometry tools. EditPolygon combines the active polygon and the other selected polygons into a new geometry.

If a selected feature is a true GML circle

Polygon-only operations require coordinates. EditPolygon displays a conversion warning before continuing. The default is 72 perimeter vertices, and Advanced options let you choose another value. Once converted for the operation, the result is an ordinary Polygon or MultiPolygon and no longer a true CircleByCenterPoint.

3. Review the merged result

  • Zoom to every former boundary and confirm the internal line was removed.
  • Check for narrow gaps, sliver holes or spikes where source boundaries almost—but did not exactly—match.
  • Confirm whether the result is Polygon or MultiPolygon.
  • Review holes: gaps between source polygons may become legitimate interior rings.
  • Rename the result and inspect retained properties.

Polygon versus MultiPolygon

Polygon result

The dissolved area is connected. It can still contain holes.

MultiPolygon result

Two or more disconnected areas remain. This is valid and should not be forced into one ring.

4. Clean up difficult merges

Boundaries almost touch

Zoom in before merging. Use snapping or edit the source boundaries so they truly share coordinates. A tiny gap cannot be dissolved as a shared edge.

Unexpected holes

Use the Hole manager to inspect each ring. Remove only holes that are genuinely unwanted. Filling every hole can erase valid islands or exclusions.

Very high vertex count

Use Simplify only after confirming the merge. Start with a conservative tolerance and preview the result. Simplification is not a substitute for fixing mismatched source boundaries.

5. Validate the result

Open GIS → Check & fix geometry and run Geometry Health on the result. Apply safe cleanup first, then review any consequential repairs. A complex dissolve can produce technically valid but operationally undesirable geometry, so compare the result with the source layers.

6. Export the merged feature

Select only the merged feature when you want a file containing the result alone. Choose Selected as the scope, then select KML, KMZ, GeoJSON, GML, Shapefile ZIP, WKT, CSV or TopoJSON as required.

Troubleshooting

Merge is unavailable

At least two editable polygons must be selected. Unlock features or layers and confirm the selection count.

The internal boundary remains

The features may not overlap or share identical boundary coordinates. Inspect the edge at a high zoom level.

The result contains many tiny holes

The source data probably contains gaps or slivers. Review holes individually rather than filling all of them automatically.

The result lost important attributes

Merging several records into one requires an attribute decision. Restore the source or use Undo, then record the values you want on the merged feature.

Merge checklist
  • All intended polygons—and only those polygons—were selected.
  • Source boundaries were checked for gaps and overlaps.
  • The Polygon/MultiPolygon result is expected.
  • Holes and slivers were reviewed.
  • Name and properties describe the merged result.
  • The result was validated before export.
