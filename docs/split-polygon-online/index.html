Split a polygon online

Use this guide for deliberate line-based polygon division.

Before splitting

A split creates new boundary segments where the cutting line crosses the polygon. Save the original file or project first. Ensure the active feature is the one you intend to divide and hide unrelated layers if they make the map difficult to read.

1. Select the active polygon

Click the polygon on the map or in Layers. Confirm its name, geometry type, parts, holes and bounds in the Inspector. Split operates on the active polygon, not every selected feature.

2. Choose Split active by drawn line

  1. Open Geometry tools.

    Select Split active by drawn line.

  2. Select Run.

    The editor changes to line drawing mode.

  3. Draw across the polygon.

    Click the first point outside the polygon, add intermediate points if necessary, and finish outside the polygon on the other side. Press Enter to finish.

  4. Review the preview.

    Check the cut width and resulting parts before applying.

What makes a reliable cutting line?

  • It crosses the polygon boundary at least twice.
  • It extends beyond the polygon at both ends.
  • It does not run exactly along an existing boundary.
  • It avoids unnecessary loops and self-crossings.
  • It crosses the intended polygon part when working with a MultiPolygon.
A line that only touches the boundary may not split the polygon. Zoom in and make the line clearly enter and exit the interior.

Cut width and precision

The operation uses a very narrow buffered line to create the cut. Increase the width only when the source geometry or scale requires it. A large cut width removes a visible corridor rather than creating a minimal separation.

Splitting polygons with holes or multiple parts

Holes

A cut can intersect a hole, create new holes or redistribute existing rings between output parts. Open Hole manager after the split and inspect each result.

MultiPolygon

The line may cross only one part. Uncrossed parts remain in the geometry and can affect whether the output is a Polygon or MultiPolygon. Consider separating parts first when you need independent feature records.

3. Review and name the output

After applying the split, inspect each resulting part. Confirm that new boundaries meet the intended locations, no narrow slivers were created, and properties or names distinguish the outputs.

Use Undo immediately when the line produced an unexpected result. Redraw the line at a closer zoom or adjust cut width.

4. Validate the split geometry

Run More → Validate / repair polygons. Pay particular attention to self-intersections, tiny rings, duplicate coordinates and invalid hole placement near the cut.

5. Export the result

Use Selected when exporting one output part, or select all resulting parts before exporting the complete split. Confirm that original unsplit geometry is not also included unless you intend to retain it.

Troubleshooting

The line does not split the polygon

Extend it farther beyond both sides, avoid tracing the boundary and confirm the correct polygon is active.

Only one MultiPolygon part was divided

The line crossed only that part. Draw a line through every intended part or split parts separately.

The split created a visible gap

Reduce the cut width and rerun. The line buffer may be too large for the map scale.

A tiny sliver was created

The line may pass very close to a vertex or nearly follow an edge. Undo and redraw a cleaner crossing.

Split checklist
  • The correct polygon was active.
  • The cut line started and ended outside the polygon.
  • Cut width was appropriate for the scale.
  • All result parts and holes were inspected.
  • Names and properties identify the outputs.
  • Validation passed before export.
