Online GeoJSON polygon editor

A thorough workflow for GeoJSON Polygon and MultiPolygon features.

Choose visual editing or geometry-code editing

GeoJSON is both a GIS interchange format and a readable JSON structure. EditPolygon supports two complementary workflows: use the map for spatial editing, or use Geometry code when you need direct access to coordinates.

Visual editor

Best for moving boundaries, adding or deleting vertices, drawing holes and understanding spatial relationships.

Geometry code

Best for replacing known coordinates, inspecting ring structure or correcting a small, identifiable JSON problem.

1. Open or create GeoJSON

Select Open and choose a .geojson or .json file, or draw a new feature using the Draw tool. The imported data appears as a layer. Use Fit if the map does not immediately frame it.

2. Understand the geometry structure

Coordinate order

GeoJSON coordinates use longitude, latitude order. A coordinate near Brisbane might therefore look like [153.02, -27.47], not the latitude-first order commonly shown in user interfaces.

Polygon rings

A Polygon contains an array of rings. The first ring is the exterior boundary. Later rings are holes. Each ring should close by repeating its first coordinate at the end.

MultiPolygon

A MultiPolygon contains multiple separate polygons. Each part can have its own exterior and holes. A merge operation may create a MultiPolygon when selected areas do not touch.

Do not manually change nesting levels unless you understand the geometry type. A syntactically valid JSON array can still describe the wrong geometry structure.

3. Edit visually on the map

Click the feature, confirm its geometry in the Inspector and select Edit polygon. Drag red handles to move existing coordinates. Click a green midpoint to insert a coordinate. Use lasso selection for several vertices, and use snapping or topology only when you intend boundaries to align.

4. Edit GeoJSON coordinates directly

  1. Open Geometry code.

    The Inspector shows the geometry object for the active feature—not the entire FeatureCollection.

  2. Format and inspect.

    Confirm the type and coordinate nesting. Look for swapped axes, missing closing coordinates or an unintended hole.

  3. Make the smallest necessary change.

    Avoid replacing a large geometry when a visual edit is safer.

  4. Apply geometry.

    Review any validation messages and suggested cleanup before committing.

5. Preserve feature names and properties

GeoJSON Features can contain arbitrary values in properties. Renaming in EditPolygon updates the feature name used by the editor. Before exporting, verify that operational fields—such as status, category, identifier or source—remain present.

Geometry-only operations may combine several features. When merging, decide which properties should describe the result; no generic tool can always infer the correct attribute values.

6. Check the geometry

Open GIS → Check & fix geometry. Geometry Health checks the selected layer, explains structural problems in plain language and links each issue back to the map. Apply safe cleanup in bulk, but preview and accept shape-changing repairs individually. Validation can make geometry technically usable; it cannot determine whether the boundary is factually correct.

7. Export GeoJSON

Choose All, Selected or Visible, select GeoJSON, and export. Preserve full precision for authoritative boundaries. Rounding may be useful for lightweight visualisation data but permanently changes coordinates in the downloaded copy.

Common GeoJSON errors

The file is valid JSON but does not import

It may not contain a supported GeoJSON Feature, FeatureCollection or geometry, or the geometry may be nested incorrectly.

The polygon appears on the wrong continent

Longitude and latitude are probably reversed, or projected coordinates were supplied without conversion to geographic longitude/latitude.

A hole appears filled

Check ring nesting and orientation, and confirm the hole coordinates are contained within the exterior ring.

The output is a MultiPolygon after merge

This is expected when merged areas remain spatially separate. A single Polygon is only possible when the dissolved result is connected.

When a desktop GIS is safer

Use a desktop GIS when you need CRS transformation, advanced attribute joins, topology rules across many layers, very large datasets, database editing or authoritative metadata management. EditPolygon is designed for focused browser-based geometry work.

GeoJSON checklist
  • Coordinates use longitude, latitude order.
  • Polygon and MultiPolygon nesting is correct.
  • Exterior rings and holes are intentional.
  • Required properties remain present.
  • Validation issues were reviewed.
  • Precision and simplification choices are documented.
