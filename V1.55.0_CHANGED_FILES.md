# EditPolygon v1.55.0 changed files

v1.55.0 is the **Map abstraction** release. Leaflet remains the production renderer, but active editor viewport, coordinate, event and interaction-state operations now go through the new map runtime in preparation for the OpenLayers parity build.

## New files

- `GIS_MAP_ABSTRACTION_RELEASE_NOTES.md` — architecture, transitional boundaries, test status and v1.55.1 plan.
- `docs/assets/editpolygon-map-adapter.js` — engine-neutral map runtime contract plus the v1.55.0 Leaflet-backed implementation.
- `tests/browser-map-adapter-smoke.py` — focused browser smoke test for the real adapter asset.
- `tests/map-abstraction-integration.test.mjs` — integration/load-order and direct-dependency regression guards.
- `tests/map-adapter.test.mjs` — unit tests for coordinate/view/event/interaction behaviour and Leaflet recovery containment.
- `V1.55.0_CHANGED_FILES.md` — this manifest.

- `GIS_FOUNDATION_NOTES.md` — documents the v1.55 map-engine boundary.
- `README.md` — updates the application baseline, tests and staged OpenLayers roadmap.

## Deliberately unchanged in v1.55.0

The release does **not** replace Leaflet rendering yet. Basemap/reference/remote layer construction, Leaflet vector/marker/circle objects, label/measurement overlays and other native renderer layers remain in place for v1.55.1 parity work. `EditPolygonMap.getNativeMap()` is a temporary compatibility bridge for those paths.

There is no project-format, CRS, geometry, schema, history, Geometry Health or import/export semantic change in v1.55.0.

## Deletions

**None.** Uploading the v1.55.0 GitHub patch over v1.54.2 does not require deleting any existing repository files.
