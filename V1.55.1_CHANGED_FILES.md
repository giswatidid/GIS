# EditPolygon v1.55.1 changed files

v1.55.1 is the OpenLayers parity-preview release. It adds an optional OpenLayers-backed map runtime while retaining Leaflet as the default and as a temporary compatibility overlay for specialised renderer paths.

No v1.55.0 files are intentionally deleted by this release.

## New files

- `GIS_OPENLAYERS_PARITY_RELEASE_NOTES.md` — architecture, engine switch, parity boundary, tests and live-test checklist.
- `docs/assets/editpolygon-openlayers.css` — transitional OpenLayers/Leaflet compatibility-surface layout and control styling.
- `tests/browser-openlayers-parity-smoke.py` — focused browser smoke test for the OpenLayers runtime contract.
- `V1.55.1_CHANGED_FILES.md` — this manifest.

## Modified application/runtime files

- `docs/index.html` — v1.55.1 cache key, conditional pinned OpenLayers parity bootstrap and parity stylesheet.
- `docs/assets/editpolygon-map-adapter.js` — dual-engine runtime, OpenLayers view/projection/event implementation, OL basemap/tile/WMS/vector primitives, synchronised Leaflet compatibility surface and safe fallback.
- `docs/assets/editpolygon-app.js` — runtime engine selection, generic display-layer helpers, OpenLayers built-in basemaps, OpenLayers cached editable vector rendering, OL XYZ/TMS/WMS service paths and compatibility-safe reference cleanup.
- `package.json` — version 1.55.1 and OpenLayers parity browser-smoke command.
- `scripts/check-repo.mjs` — integration checks for the OpenLayers assets/runtime paths and v1.55.1 load order.

## Deployment

For the GitHub-only upgrade workflow, upload the contents of the v1.55.1 patch at the repository root. Existing paths are overwritten and new paths are added; files not present in the patch are left alone.

After deployment:

- normal `/GIS/` should still use Leaflet;
- `/GIS/?mapEngine=openlayers` should request OpenLayers;
- in the browser console, `EditPolygonMap.engine` should equal `"openlayers"` for a successful OpenLayers preview;
- if the runtime falls back, `EditPolygonMap.fallbackReason` should explain why.
