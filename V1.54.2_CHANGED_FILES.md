## Live-testing issues fixed

- Advanced-rule checkboxes no longer automatically rerun Geometry Health or collapse the Advanced layer rules section. Rule changes are staged until the user explicitly runs the updated check.
- Advanced rules are geometry-aware: line-only layers show line rules, polygon-only layers show polygon rules, and mixed layers show the relevant combination.
- Import preview uses Geometry Health diagnostics instead of older heuristics that called valid short lines/points suspicious or confused duplicate vertices / overlapping MultiPolygon parts with self-intersection.
- The generic imported-polygon WGS84 assumption warning was removed; actual coordinate-range problems remain explicit.
- GEOS MakeValid previews fold harmless safe normalisation (such as ring direction) into the proposed repair instead of presenting it as unresolved geometry.
- Area/length changes are shown as not comparable when the original geometry is invalid and those percentages would be misleading.
- Repaired features no longer inherit stale legacy validation warning metadata, and Layers warning badges use the Geometry Health validator where available.
- Repeated dangling-endpoint diagnostics on the same feature are grouped into a concise count with individual locate actions.
- The `Check & fix geometry` GIS menu entry no longer displays the application version number.
