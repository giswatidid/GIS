# EditPolygon v1.54.1 changed files

This is a small follow-up patch for the v1.54.0 Geometry Health release. It does **not** require deleting any repository files. Upload these files at the same paths over the existing v1.54.0 repository.

## User-facing changes

- Geometry Health now occupies the normal right-hand Inspector column rather than opening as an oversized floating panel.
- The normal Inspector is temporarily hidden while Geometry Health is open and restored when it closes.
- Geometry Health reuses the existing Inspector section, form-control and button language.
- Workflow sections are now **Check**, **Summary**, **Issues**, **Repairs**, and **Output**.
- Diagnostics are grouped by feature; only the first problem group opens by default.
- Prominent release/version branding was removed from the working panel.
- Safe/review/manual states are compact rather than large card treatments.
- The right Inspector column is automatically expanded if it was collapsed when Geometry Health opens, then its prior collapsed state is restored on close.

## Validation corrections

- Consecutive duplicate polygon vertices are no longer falsely interpreted as self-intersections.
- A self-crossing bow-tie polygon is no longer also described as a collapsed zero-area ring merely because its signed shoelace area cancels to zero.
